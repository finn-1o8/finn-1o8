### Featured work

- **Few-Shot Flood Delineation** ([repo](https://github.com/finn-1o8/Few-shot_Flood_Delineation)): MSc thesis. SatMAE pretraining on 12k unlabelled Sentinel-2 scenes, then flood segmentation with as little as 0.5 % of the labels, including a sealed cross-dataset test on Sen1Floods11.
